# Lompat Masjid Megah

Game Informatika Kelas X oleh Ibu Dhona Arba. Bantu Faris melompat dari satu pijakan ke pijakan berikutnya untuk mencapai masjid megah.

Setiap ronde mengambil 10 soal dari bank 50 soal Keamanan Internet dan Proteksi Data. Waktu menjawab 20 detik. Jawaban benar memberi 100 poin dan membuat Faris melompat. Jawaban salah atau waktu habis mengurangi 50 poin, lalu pemain dapat mengulang soal di pijakan yang sama.

[Mainkan di GitHub Pages](https://dhonaarba1-ctrl.github.io/lompat-masjid-megah/). Untuk bermain secara offline, buka `index.html` di peramban.
